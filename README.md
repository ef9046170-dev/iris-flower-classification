# Iris Flower Classification
## Task Objective
The objective of this project is to classify iris flowers into different species using machine learning.
## Dataset Used
Iris Dataset
## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
## Model Applied
Decision Tree Classifier
## Key Results and Findings
- Data preprocessing and visualization were performed.
- The dataset was split into training and testing sets.
- A Decision Tree Classifier model was trained successfully.
- The model achieved an accuracy of 1.0 (100%).
